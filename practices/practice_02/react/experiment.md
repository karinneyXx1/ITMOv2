# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель: проверить каждый из 6 сценариев таблицы tests_load_input.md на согласованность с ограничением threadpool FastAPI (эндпоинт синхронный, `def create_review`, а не `async def`) — не противоречит ли заявленное число параллельных клиентов реальному поведению сервиса
- Доступные входы: tests_load_input.md, review_service.py и api.py из diff (через TRAINING_PR.diff)
- Разрешённые действия: прочитать строку таблицы, сравнить с кодом, зафиксировать вывод (согласовано / есть риск)
- Запрещённые действия: менять код, менять числа нагрузки (VU/RPS) без явного обоснования, придумывать реализацию threadpool, которой нет в коде
- Максимальное число шагов: 6 (по одному на сценарий)
- Условие остановки и вопроса человеку: если для вывода не хватает данных о конфигурации uvicorn/threadpool (её нет в diff) — зафиксировать как открытый вопрос и не додумывать конкретное число потоков

Есть риск (высокий) — требует явного указания числа воркеров/потоков в методике; требует уточнения (размер threadpool и число воркеров uvicorn неизвестны) |
