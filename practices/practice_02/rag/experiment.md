# RAG

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Вопрос к источникам: колонка "Evidence" в таблице сценариев tests_load_input.md сейчас ссылается только на строки кода (например, api.py:10). Есть ли в разрешённых источниках (context.md, problem.md) правила или метрики, которыми можно дополнительно обосновать каждый сценарий?

## Разрешённые источники

| Файл или документ | Зачем нужен | Какой фрагмент используем |
|---|---|---|
| context.md | правила SEC-1...OBS-1 | конкретные ID правил, соответствующие каждому сценарию |
| problem.md | метрики и описание проблемы сервиса | раздел "Метрики" |
