# Журнал экспериментов Практики 2

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Выбранный слабый артефакт Практики 1: [tests_load.md](../practice_01/tests_load.md)
- Что в нём нужно улучшить: файл содержит несколько независимых слабостей — 
  (1) сценарии описаны текстом без единого формата и инструмента, 
  (2) один из критериев прохождения сам содержит "требует уточнения", 
  (3) условие перехода к полноценному тестированию расплывчато, 
  (4) часть evidence ссылается только на код, без привязки к правилам context.md, 
  (5) не учтён риск сериализации запросов через ограниченный threadpool FastAPI. 
  Каждая из шести техник работает с отдельной копией файла и устраняет одну 
  конкретную слабость, а не все сразу.
- Как поймём, что изменение полезно: по каждой слабости — свой измеримый признак: 
  единая таблица метрик вместо текста (Few-shot), формат отчёта прогона (R.C.T.F.), 
  однозначный числовой критерий вместо условия с "требует уточнения" (Chain of 
  Verification), проверяемый триггер вместо "когда станет известно" (Tree of 
  Thoughts), evidence с цитатой правила рядом со ссылкой на код (RAG), явное 
  указание фиксировать конфигурацию threadpool в методике (ReAct).
