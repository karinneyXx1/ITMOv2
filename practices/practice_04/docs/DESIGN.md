# DESIGN.md — визуальный стиль Metro Rush

Ориентир — граффити-эстетика мобильных раннеров про метро: надпись-"бомбинг"
поверх облака пузырей, сочные градиенты, жирная обводка, искры. Берём **язык
стиля**, а не чужие ассеты: никаких логотипов, названий, персонажей и шрифтов
конкретной игры (см. «Что НЕ берём»).

## Что считано с референса
- **Надпись** — толстые округлые буквы, заливка градиентом сверху вниз:
  светло-жёлтый → жёлтый → оранжевый → красно-оранжевый, внутри — светлые
  блики. Вокруг — очень толстая тёмно-синяя (не чёрная) обводка и тень-дубль,
  сдвинутая вправо-вниз. Буквы стоят с лёгким наклоном, не по линейке.
- **Пузыри** — облако кругов разного размера за надписью: стально-голубая
  заливка с радиальным переходом, тёмная голубая обводка, белый
  блик-полумесяц в левом верхнем углу каждого круга.
- **Искры** — белые четырёхлучевые звёздочки с вогнутыми гранями.
- **Подтёки** — короткие вертикальные капли тёмной краски под буквами.
- Общее настроение — дерзко, по-уличному, мультяшно, но чисто: плоские
  заливки + один градиент, без фотореализма и шума.

## Палитра
| Токен | HEX | Где используется |
|---|---|---|
| `--ink` | `#1c2541` | Все обводки, текст, тени-дубли. Вместо чёрного |
| `--ink-soft` | `#2d3a5c` | Стёкла, вторичный текст |
| `--sun-light` | `#fff27a` | Верх градиента, блики |
| `--sun` | `#ffd92e` | Основной жёлтый: машина, монеты, балки |
| `--flame` | `#ff9a1f` | Середина градиента, борта машины |
| `--ember` | `#f2541b` | Низ градиента, стрелка тахометра, отсечка, барьеры |
| `--steel` | `#6f93c0` | Пузыри, поезда, граффити на стенах |
| `--steel-deep` | `#4a6c99` | Обводка пузырей, парапеты, фон страницы |
| `--steel-light` | `#a9c4e2` | Светлые пузыри, дальний город |
| `--mist` | `#d9e8f5` | Облака, подложки статистики, пустые индикаторы |
| `--go` | `#3ddc84` | ТОЛЬКО окно идеального переключения (огни и дуга тахометра) |

Градиент-подпись: `linear-gradient(180deg, #fff27a 0%, #ffd92e 42%, #ff9a1f 72%, #f2541b 100%)`.

## Типографика
- **Bungee** — дисплейный: заголовок METRO RUSH, счёт, номер передачи,
  итоговые очки. Только латиница и цифры.
- **Rubik** 500/700/900 — весь русский текст: подсказки, кнопки, статистика,
  всплывающие надписи («Идеально! +300»).
- Приём «граффити-текст» (`.graffiti-text`): элемент с прозрачным текстом
  держит размер, `::before` — обводка `0.2em` + тень-дубль цветом `--ink`,
  `::after` — градиентная заливка с тонким светлым контуром.
  Текст дублируется в `data-text`, при обновлении менять оба.

## Формы
- Карточки (меню-управление, приборная панель, пауза, итог): белые,
  обводка `4px --ink`, радиус `22px`, жёсткая тень `6–10px 6–10px 0 --ink`.
- Кнопки — пилюли (`999px`) с градиент-заливкой и жёсткой тенью; при наведении
  «приподнимаются», при нажатии «вдавливаются» в тень.
- Клавиши `<kbd>` — белые «колпачки» с нижней тенью `0 3px 0 --ink`.
- Стикер «Новый рекорд!» — жёлтая пилюля, повёрнута на 8°.

## Сцена (canvas)
| Элемент | Решение |
|---|---|
| Небо | Градиент `#5d8fd0 → #cfe4f6`, облака — кластеры пузырей с бликами, медленно дрейфуют |
| Город | Два слоя силуэтов стально-голубых оттенков у горизонта, параллакс от камеры |
| Пути | Три колеи: насыпь, деревянные шпалы, светлые рельсы; поперечные полосы гравия для ощущения скорости |
| Стены | Бетонные панели по бокам, на ~65% панелей — абстрактные граффити: пузыри + «буквы»-плашки с градиентом, подтёки, искры |
| Арки | Жёлтые балки с диагональной тёмной штриховкой каждые 64 м — ритм и глубина |
| Машина игрока | Жёлто-оранжевая с градиентом на задней панели (как буквы подписи), тёмные стёкла, стоп-сигналы загораются при торможении, голубое пламя при нитро |
| Поезда | Три ливреи: стальная с жёлтой полосой, оранжевая с тёмной, белая с красной |
| Барьеры | Белая доска с красно-оранжевой диагональю на тёмных стойках |
| Монеты | Золотой градиент, вращаются; при подборе — искры |
| Туман | Дальние объекты плавно растворяются в цвете горизонта |

Все объекты сцены обведены `--ink`, толщина обводки зависит от дальности
(1–4 px) — это главный приём, который связывает 3D-сцену с плоским UI.

## HUD
- Слева сверху — счёт граффити-шрифтом + множитель-пилюля (голубеет при нитро).
- Справа сверху — монеты, рекорд, таймер магнита.
- Справа снизу — приборная панель: 5 огней переключения (жёлтые по мере роста
  оборотов → все зелёные в окне идеального переключения → мигают красным на
  отсечке), тахометр с зелёной и красной зонами, крупный номер передачи,
  скорость в км/ч, полоска нитро.
- По центру — короткие всплывающие надписи на события. Без постоянного шума.

## Движение
- Анимация, не вызванная игроком, — только искры в меню и облака.
- `prefers-reduced-motion`: отключаются тряска камеры, линии скорости,
  мерцание искр, вращение монет.

## Что НЕ берём
- Логотипы, названия, персонажей, фирменные шрифты и иллюстрации любых
  существующих игр — это чужая интеллектуальная собственность.
- Надпись в меню — собственное название Metro Rush, набранное открытым
  шрифтом Bungee; пузыри и искры нарисованы CSS/canvas с нуля.
