## Context Pack для первого рабочего сценария

### Факты и правила

- SEC-1: перед отправкой во внешний LLM из diff удаляются токены, пароли и приватные ключи.
- API-1: diff длиннее 20 000 символов отклоняется с HTTP 413.
- REL-1: внешний LLM-вызов имеет timeout 10 секунд; ошибка превращается в контролируемый ответ.
- SCOPE-1: сервис только советует; он не пишет код и не выполняет действия в GitHub.
- QA-1: риск включается в ответ, только если он подтверждён строкой diff или правилом репозитория.
- OBS-1: в лог пишутся только request_id, длительность и статус.

### Формат входа и результата

- OUT-1: ответ содержит summary, массив risks (максимум 3 элемента с полями file, line, evidence, risk) и массив checks.

### Ограничения и запрещённые действия

- Помощник не может approve, merge или менять код (SCOPE-1).
- Нельзя включать риск без доказательства из diff или правила репозитория (QA-1).

### Хороший пример

app/review_service.py:16 — diff отправляется во внешний LLM без удаления секретов,
что нарушает SEC-1. Проверка: передать diff с тестовым token и убедиться,
что в prompt осталось [REDACTED].

### Плохой пример

Код можно улучшить. Добавьте тесты и обработку ошибок.

### Что пока неизвестно

- Какая конкретно реализация LLM используется в app.dependencies.review_service (модель, ключи, таймауты).
- Есть ли аутентификация на /api/reviews — по diff эндпоинт открыт.
- Версия Python и зависимостей проекта не зафиксирована в репозитории (requirements.txt для практики 1 пуст) — рекомендации, зависящие от версии (Pydantic v1/v2, синтаксис dict[str, str], требующий Python 3.9+), нельзя проверить и принимать как окончательные.

## Как использовали AI

- Для чего: анализ TRAINING_PR.diff и выявление рисков согласно правилам Context Pack (SEC-1, API-1, REL-1, OUT-1, SCOPE-1, QA-1, OBS-1).
- Тип промпта: master prompt.
- Строка в [`prompts.md`](prompts.md): P1-02.
- Что проверили и исправили сами: сопоставили каждый risk с конкретными строками diff и правилами; проверили формат ответа на соответствие OUT-1; пересчитали заголовки хантков (@@) и подтвердили целостность diff.
