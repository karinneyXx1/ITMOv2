# Промпт для макета (v0.app)

## Запрос 1 — первый вариант

```
Сделай интерактивный прототип веб-интерфейса «Код-репетитор» на React + TypeScript + Tailwind + shadcn/ui.
Весь текст интерфейса на русском.

Кто пользуется: репетитор по программированию. Задача: выдать ученику домашнее задание и увидеть его в списке.

Экраны:
1. Вход: карточка по центру, поля «Email» и «Пароль» с подписями, кнопка «Войти».
2. «Домашние задания»: шапка с логотипом «Код-репетитор», именем пользователя и кнопкой «Выйти»;
   заголовок страницы, справа основная кнопка «+ Выдать задание»;
   список карточек: название, «Ученик: …», срок «до 20 ноября 2026 г.», бейдж статуса (Выдано / Сдано / На доработке / Проверено).
3. Диалог «Новое домашнее задание»: поля «Ученик» (выпадающий список), «Название», «Описание» (необязательно),
   «Срок сдачи» (дата); кнопки «Отмена» и «Выдать задание».

Покажи все состояния. Добавь сверху переключатель состояний, чтобы их можно было посмотреть:
- вход: пустая форма, ошибки под полями («Введите email»), ошибка сервера «Неверный email или пароль»;
- список: загрузка (скелетоны карточек), пусто («Пока нет заданий» + кнопка «Выдать первое задание»),
  список заданий, ошибка загрузки с кнопкой «Повторить», сообщение об успехе «Задание «…» выдано: Анна Смирнова»;
- форма: заполнение, ошибки под полями («Выберите ученика», «Введите название задания», «Срок сдачи не может быть в прошлом»),
  сохранение (кнопка заблокирована, спиннер и текст «Сохраняем…»), ошибка сервера вверху формы с сохранёнными данными.

Требования: только готовые компоненты shadcn/ui (Button, Input, Textarea, Label, Card, Dialog, Badge, Alert, Skeleton),
основной цвет — индиго, у всех полей подписи, видимое кольцо фокуса, вёрстка работает на ширине 375 px.
```

## Запрос 2 — доработка: красивее и ближе к требованиям

Первый вариант (скриншоты `v0-v1-*.png`) был слишком простым: однотонные карточки, нет сводки и описания задания, пустое состояние и загрузка без акцентов, у срока сдачи нет подсказки.

```
Отличный первый вариант. Сделай интерфейс красивее и «живее», сохранив тёмную тему, индиго и все состояния в переключателе.

Шапка и общий вид:
- лёгкий индиго-градиент/свечение за шапкой страницы «Домашние задания», логотип </> в скруглённом квадрате с индиго-фоном;
- под заголовком подзаголовок «Задания, которые вы выдали ученикам»;
- аккуратные тени и hover у карточек (лёгкий подъём и подсветка рамки), плавные переходы.

Сводка над списком — ряд из 4 небольших карточек со счётчиками: «Выдано», «Сдано», «На доработке», «Проверено» (число крупно, подпись мелко, цветная иконка статуса). На телефоне — сетка 2×2.

Карточка задания:
- слева цветная полоска по статусу (тот же цвет, что у бейджа);
- аватар ученика с инициалами (кружок с цветным фоном) рядом с «Ученик: …»;
- описание задания, если есть, — одной-двумя строками серым под названием;
- если срок прошёл, а задание не проверено — дата красная с подписью «просрочено».

Пустое состояние: крупная иконка в круге с индиго-свечением, заголовок «Пока нет заданий», текст «Выдайте первое задание — оно появится здесь и у ученика», кнопка «Выдать первое задание».
Загрузка: скелетоны повторяют форму карточки (полоска, строка названия, аватар, дата), плюс скелетоны сводки.
Успех: зелёная плашка с иконкой галочки над списком, а не всплывающее уведомление.
Ошибка загрузки: карточка с красной иконкой, текстом причины и кнопкой «Повторить».

Вход: на фоне мягкое индиго-свечение, карточка по центру; под кнопкой мелкий текст «Демо: tutor@example.com».

Диалог «Новое домашнее задание»:
- «Ученик» — нативный <select> (shadcn NativeSelect), в списке пункт «— не выбран —»;
- ошибки — красным текстом под полем, поле с красной рамкой;
- под «Срок сдачи» подсказка «Не раньше сегодняшнего дня»;
- при ошибке сервера — красная плашка вверху формы, введённые данные остаются.

Обязательно: только компоненты shadcn/ui, у всех полей подписи, видимое кольцо фокуса у кнопок и полей, работа с клавиатуры, вёрстка без горизонтальной прокрутки на 375 px (кнопка «Выдать задание» под заголовком, имя пользователя в шапке скрыто).
```
