# Contract: тестовый хук `window.__metro` (дополнения для заданий)

Существующие поля (`world`, `mode`, `garage`, `start`, `command`, `pause`) не меняются.

| Поле / метод | Что делает | Зачем |
|---|---|---|
| `missions` (getter) | текущее состояние дня (контракт, 2.3) | проверки прогресса и `seen` |
| `setNow(ts)` | задаёт «сейчас» для `main.js` (`now() = ts + ход реального времени с момента вызова`) | смена дня без ожидания полуночи |
| `refreshMissionsDay()` | немедленно выполняет проверку дня, как по таймеру | детерминированный тест автозачисления в меню |
| `claimMission(id)` | вызывает тот же обработчик, что кнопка «Забрать» (с обработкой ошибок) | проверка отказов (`not-completed`, `stale-day`) без DOM-хитростей |

Хук не влияет на логику `game.js`; в игре без тестов не используется.
