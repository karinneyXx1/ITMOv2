- раздел 3 — 11 операций логики `game.js` (вход, выход, коды ошибок);
- раздел 4 — ошибки и реакция UI;
- раздел 5 — точки вызова в `main.js`;
- раздел 6 — тексты UI по виду задания;
- раздел 7 — принятые ограничения.

[test-hooks.md](test-hooks.md): интерфейс тестового хука для сквозных проверок.
