# Quickstart: проверка ежедневных заданий

## Предусловия
`cd practices/practice_05`; `mcp/node_modules` установлены; `venv` с Playwright (см. AGENTS.md).

## Автоматически
```bash
sh scripts/check.sh --full      # ожидание: последняя строка CHECK: PASS
node test_game.js               # тесты логики заданий — блок «задания: …»
venv/bin/python test_browser.py # сценарий 10 «Ежедневные задания»
```

## Вручную (сквозной сценарий US1)
1. Открыть `index.html`, в меню — «Задания 0/3» и «Новые!».
2. Открыть «Задания» → три строки, таймер, «Новые задания на сегодня».
3. Esc → меню, Enter → заезд; собрать монеты до цели лёгкого задания (см. экран).
4. После аварии — блок «Задания дня» с «+N» и «Выполнено!»; в меню — «Награда!».
5. «Задания» → «Забрать +20» → кошелёк +20; «Гараж» — та же сумма.

## Смена дня (US3) — из консоли браузера
```js
window.__metro.setNow(Date.now() + 24 * 3600 * 1000);
window.__metro.refreshMissionsDay();   // в меню: «Вчерашние награды: +N…», если была незабранная
```

## Ошибки и границы (US4)
- `window.__metro.claimMission(window.__metro.missions.missions[0].id)` до выполнения → «Задание ещё не выполнено: X из Y».
- `localStorage.setItem('metro-rush-missions', '{мусор')` + перезагрузка → задания с нулём, гараж цел.

Ожидаемые результаты — сценарии US1–US5 в [spec.md](spec.md).
